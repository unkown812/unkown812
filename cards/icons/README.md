Vendored icon masks used by `scene.py` for the themed badges and tech grid.

- Brand icons: [Simple Icons](https://simpleicons.org/) (CC0 1.0)
- UI icons: [Material Design Icons](https://materialdesignicons.com/) via Iconify (Apache 2.0)

Each PNG is a flat white mask at 128×128. `scene.py` tints it with the active
theme's accent colour, so one set of icons works for sunset and morning.
